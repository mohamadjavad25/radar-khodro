# رادار خودرو

پایش خودکار و تحلیل بازار آگهی‌های خودرو در دیوار. هر خودرویی، هر شهری.

## وضعیت

- API واقعی دیوار شناسایی و تست شده
- کاتالوگ **۱۶۵ برند و ۲۱۹۸ مدل**، ساخته‌شده از فیلترهای خود دیوار
- فیلتر ساختاری برند/مدل (نه فقط جست‌وجوی متنی)
- مشخصات کامل خودرو از صفحهٔ آگهی: **شاسی، بدنه، موتور، گیربکس، رنگ، سوخت**
- **زمان انتشار** به‌صورت نسبی («۳ روز پیش») و تبدیل به تاریخ واقعی
- **بوکمارک** و **علامت‌گذاری «دیده شدم»**
- امتیاز **سود خرید و فروش مجدد** بر پایهٔ اختلاف با میانهٔ بازار
- رابط کاربری مینیمال، واکنش‌گرا برای دسکتاپ و موبایل
- ۱۰۱ تست

## منطق «سود»

مبنای قیمت فروش مجدد = **میانهٔ بازار همان مدل و همان سال**.

- `سود تخمینی = میانهٔ بازار − قیمت آگهی`
- اگر قیمت آگهی بیشتر از ۶۰٪ میانه باشد، سود صفر در نظر گرفته می‌شود
- اگر قیمت زیر ۴۰٪ میانه باشد، مشکوک به قیمت غیرواقعی است
- **امتیاز شکار** = ترکیبی از حاشیهٔ سود (۵۵٪)، وضعیت بدنه و شاسی (۲۵٪)، و تازگی (۲۰٪)

## زمان انتشار

از خط پایین هر کارت در لیست دیوار خوانده می‌شود و به تاریخ واقعی تبدیل می‌گردد:

| متن دیوار | معادل |
|---|---|
| لحظه پیش | ۱ دقیقه |
| یک ربع پیش / نیم ساعت پیش | ۱۵ / ۳۰ دقیقه |
| ۳ ساعت پیش | ۳ ساعت |
| ۲ روز پیش | ۴۸ ساعت |
| ۱ هفته پیش | ۱۶۸ ساعت |

## بوکمارک و دیده‌شده

- **ستاره** در گوشهٔ هر کارت — فهرست دلخواهت که دائمی ذخیره می‌شود
- **X** — یعنی این را دیدم، از فهرست پنهان می‌شود ولی پاک نمی‌شود
- سگمنت بالای فهرست: بین «همه» و «بوکمارک‌ها» جابه‌جا شو

```powershell
.\run.cmd bookmarks                 # نمایش در ترمینال
.\run.cmd bookmarks --remove <id>    # حذف از بوکمارک
```

## اجرا

**روی هر ویندوزی، با یک دابل‌کلیک:**

```
start.bat
```

همین. فایل را دابل‌کلیک کن. خودش همه‌چیز را انجام می‌دهد:

| کار | توضیح |
|---|---|
| پیدا کردن پایتون | نسخه‌های ۳٫۹ تا ۳٫۱۴ را به‌ترتیب امتحان می‌کند |
| نصب `playwright` | فقط اگر نباشد (از `requirements.txt`) |
| دانلود مرورگر | فقط بار اول، روی سیستم جدید |
| ساخت `config.json` | از روی نمونه، اگر وجود نداشته باشد |
| بستن نمونهٔ قبلی | اگر پورت ۸۷۶۵ اشغال باشد |
| باز کردن مرورگر | خودکار روی `http://127.0.0.1:8765` |

پنجرهٔ سیاه را باز نگه دار تا کار کند؛ با `Ctrl+C` یا بستن پنجره متوقف می‌شود.

### انتقال به سیستم دیگر

کل پوشه را کپی کن و `start.bat` را آنجا دابل‌کلیک کن. هیچ مسیر مطلقی در پروژه
نیست. تنها پیش‌نیاز، پایتون ۳٫۹ به بالاست (از python.org، با تیک
**Add python.exe to PATH**)؛ بقیه خودکار نصب می‌شود.

### اجرا از خط فرمان

```powershell
cd <پوشهٔ پروژه>
.\run.cmd web
```

> در PowerShell باید `.\` بگذاری و برای وب پارامتر `web` را اضافه کنی.

## ساختار درخواست (کشف‌شده)

```
POST api.divar.ir/v8/postlist/w/search
```

```json
{
  "search_data": {
    "form_data": { "data": {
      "category": { "str": { "value": "light" } },
      "brand_model": { "repeated_string": { "value": ["Peugeot 206", "Pride 131"] } }
    }},
    "server_payload": {
      "@type": "type.googleapis.com/widgets.SearchData.ServerPayload",
      "additional_form_data": { "data": { "sort": { "str": { "value": "sort_date" } } } }
    }
  },
  "city_ids": ["7"]
}
```

- `city_ids` = `7` برای اهواز
- `brand_model` **نام نمایشی** دیوار را می‌گیرد (مثلاً `Peugeot 206`)، نه slug
- صفحه‌بندی با `pagination_data` که از پاسخ قبلی برمی‌گردد
- درخواست‌ها داخل مرورگر واقعی ارسال می‌شوند (درخواست مستقیم HTTP کد ۴۰۳ می‌گیرد)

صفحهٔ وب متناظر: `https://divar.ir/s/ahvaz/car/peugeot/206`

## رابط کاربری

- **فیلترها:** جست‌وجوی متنی، برند و مدل (با جست‌وجوی داخلی)، سال، کارکرد، قیمت، درصد تخفیف از بازار، حداقل امتیاز
- **مرتب‌سازی:** جدیدترین، بیشترین تخفیف، بیشترین امتیاز، ارزان‌ترین، گران‌ترین
- **نوار بازار:** میانهٔ هر مدل با تعداد نمونه، قابل کلیک برای فیلتر
- **دکمهٔ دریافت:** دریافت زنده با لاگ، بدون قفل شدن رابط
- **موبایل:** فیلترها در کشوی کناری، کارت‌ها به‌جای جدول

## فقط خودروهای تعیین‌شده اسکن می‌شوند

برخلاف نسخهٔ قبلی، دیگر همهٔ خودروهای شهر پردازش نمی‌شود. دریافت فقط روی
`targets`‌های فعال انجام می‌گیرد:

```json
"targets": [
  { "id": "pride-131", "paths": ["pride/131"], "enabled": true },
  { "id": "peugeot-206", "paths": ["peugeot/206"], "enabled": true },
  { "id": "peugeot", "brand_paths": ["peugeot"], "enabled": false }
]
```

اگر هیچ هدف فعالی نباشد، برنامه هشدار می‌دهد و چیزی اسکن نمی‌کند.
برای اسکن کل شهر، `"search": {"fetch_all_cars": true}` را صریح تنظیم کن.

### چرا نتیجه‌ها را خودمان هم فیلتر می‌کنیم

فیلتر `brand_model` در API دیوار (v8) **اعمال نمی‌شود**. اندازه‌گیری شد: جست‌وجوی
`Pride 131` در اهواز هم وانت پراید و پراید ۹۰ را برمی‌گرداند (۱۱ مورد از ۲۳).

بنابراین علاوه بر فیلتر سمت سرور، هر آگهی با مسیر کاتالوگ خودش (`vehicle_path`)
مقابله می‌شود و موارد خارج از هدف کنار گذاشته می‌شوند:

```
صفحه 1: 12 از 23 ردیف (11 خارج از هدف حذف شد)
```

پیامدها:

- `total_rows` که دیوار می‌فرستد، شمارش **پیش از** فیلتر است و عدد بزرگ‌تری نشان می‌دهد.
- چون بخشی از هر صفحه کنار گذاشته می‌شود، برای پوشش کامل بازار `pages` را بزرگ‌تر بگیرید.
- اگر واقعاً وانت پراید ۱۳۱ هم می‌خواهید، مسیرش را کنار مدل اضافه کنید:
  `"paths": ["pride/131", "pride/pickup"]`

## تنظیم هدف‌ها

| کلید | معنی |
|---|---|
| `paths` | مسیر دقیق مدل (از `catalog` بگیرید) — زیرمسیرها هم شامل می‌شوند |
| `brand_paths` | کل برند |
| `query` | جست‌وجوی متنی آزاد |
| هیچ‌کدام | فقط وقتی `fetch_all_cars` روشن باشد |

برای دیدن مسیرها:

```powershell
.\run.cmd catalog
.\run.cmd catalog --brand "پژو ۲۰۶"
```

## قوانین اعلان

```json
{
  "id": "under-market",
  "name": "زیر قیمت بازار",
  "paths": ["pride/131"],
  "min_year": 1395,
  "max_mileage_km": 150000,
  "max_discount_vs_market": 0.08,
  "exclude_business": true,
  "exclude_suspicious": true
}
```

| کلید | معنی |
|---|---|
| `paths` | مدل‌های مجاز |
| `min_year` / `max_year` | بازهٔ سال شمسی |
| `max_mileage_km` | حداکثر کارکرد |
| `min_price_toman` / `max_price_toman` | بازهٔ قیمت |
| `max_discount_vs_market` | حداقل اختلاف با میانهٔ بازار (۰.۰۸ = هشت درصد) |
| `exclude_business` | حذف آگهی مغازه‌ای |
| `exclude_suspicious` | حذف قیمت‌های غیرواقعی |

## شناسهٔ شهرها

از سایت دیوار یا با انتخاب شهر به دست می‌آید. مثال: تهران `1`، مشهد `8`، اهواز `7`، شیراز `10`.

## ساختار

```
src/pride_radar/
  catalog.py    کاتالوگ برند/مدل از فیلترهای دیوار
  text.py       نرمال‌سازی فارسی و تجزیهٔ قیمت
  models.py     تطبیق خودرو، سال، کارکرد
  parse.py      تبدیل پاسخ v8 به Listing
  client.py     کلاینت API مبتنی بر مرورگر
  db.py         SQLite با حذف تکراری و تاریخچهٔ قیمت
  market.py     میانه، حذف داده پرت، مقایسه با بازار
  rules.py      موتور قوانین و امتیازدهی
  pipeline.py   هماهنگ‌کنندهٔ اجرا
  notify.py     کنسول و اعلان ویندوز
  web.py        سرور و API
  ui/           رابط کاربری
  cli.py        فرمان‌ها
```

## نکات

- قیمت و کارکرد در دیوار متن هستند نه عدد، پس کاملاً از متن فارسی استخراج می‌شوند.
- قیمت‌های غیرمنطقی (مثل ۱٬۰۰۰ تومان) در میانهٔ بازار وزن نمی‌گیرند و با برچسب قرمز علامت می‌خورند.
- مبنای مقایسه، میانهٔ همان مدل و همان سال است، نه کل بازار.
- اجرای زیاد و پشت‌سرهم ممکن است محدودیت حساب بیاورد؛ `delay_max_seconds` را بالا نگه دار.
